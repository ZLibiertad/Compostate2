# CompostAR 🌱

Aplicación web de **Realidad Aumentada** enfocada en la educación ambiental sobre compostaje. 
Desarrollada como proyecto educativo para concientizar sobre el reciclaje orgánico y la reducción de residuos domésticos.

## ¿Qué hace?

Usa la cámara del dispositivo para mostrar objetos 3D relacionados con el compostaje al apuntar a marcadores imprimibles (imágenes específicas que activan la experiencia AR).

## Tecnologías utilizadas

- HTML5 / CSS3 / JavaScript
- Realidad Aumentada web (AR.js / A-Frame)
- Google Fonts (Poppins)

## ¿Cómo usarlo?

1. Abrí la app desde el navegador de tu celular
2. Permití el acceso a la cámara
3. Descargá e imprimí los marcadores incluidos en la página
4. Apuntá la cámara al marcador y disfrutá la experiencia

## Marcadores disponibles

- 🍌 Marcador Banana
- 🍶 Marcador Botella
